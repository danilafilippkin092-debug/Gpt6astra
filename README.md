# DBY-W09 — экспериментальный UEFI-комплект

## Новая диагностическая сборка: native-diag-01

[Скачать DBY-W09-native-diag-01.zip](https://github.com/danilafilippkin092-debug/Gpt6astra/raw/refs/heads/main/DBY-W09-native-diag-01.zip) · [Описание и ограничения](NATIVE-DIAG-01.md) · [SHA-256](NATIVE-DIAG-01.sha256)

Собрана с родными компонентами предоставленного XBL и исправленными резервированиями памяти. Цель — диагностический экран, GOP, Block IO, USB и кнопки. **Это не Windows: ACPI и автоматический запуск ОС исключены. На физическом планшете не испытана, доверенной подписи Huawei нет.** Публикация комплекта согласована владельцем; исходные резервные копии в репозиторий не добавлены.

## Старый комплект — не запускать

> **Статус образа: предварительный эксперимент, запуск отложен до завершения адаптации.** Не используйте IMG из ZIP для прошивки или временной загрузки. Предыдущие структурные проверки не подтверждают аппаратную совместимость. Нового проверенного образа пока нет.

## Сохранение выбранных разделов через Termux

Добавлен [capture-termux.sh](capture-termux.sh). Скачайте файл и выполните `bash capture-termux.sh` в Termux на планшете с уже работающим root. Подробности ограничений находятся в самом скрипте. Он только читает выбранные разделы, сохраняет сжатые копии в новую папку Download и проверяет размеры и хеши. Это не полный бэкап накопителя и не гарантия восстановления. Скрипт не отправляет файлы автоматически; данные устройства остаются у пользователя.

[Скачать комплект ZIP](https://github.com/danilafilippkin092-debug/Gpt6astra/raw/refs/heads/main/DBY-W09-UEFI-test-kit.zip)

**Это тестовый UEFI-кандидат, а не готовая Windows.** Запуск на физическом планшете и загрузка Windows не проверены. Автоматической прошивки разделов в комплекте нет.

В архиве находятся собранный UEFI-образ, исходные поправки, журналы, проверки и `RUN-CAPTURE.cmd` для автоматического чтения выбранных загрузочных разделов с проверкой размеров и SHA-256. Скрипт требует уже работающих ADB и root, не записывает разделы и не перезагружает планшет.

После распаковки сначала прочитать `START-HERE.txt`, `README-RU.md` и `VALIDATION-RU.md`. Не прошивать образ как подтверждённую рабочую замену boot/kernel/abl/xbl.

Проверки: 56 тестов утилит, 44 проверки собранного артефакта и встроенная проверка 53 EFI-модулей. [Подробный отчёт](VALIDATION-RU.md). Контрольная сумма архива — в [SHA256SUMS.txt](SHA256SUMS.txt).

Исходная точка UEFI: [WQSQW/uefi-dby_w09](https://github.com/WQSQW/uefi-dby_w09/tree/423e222159dfa159d788769554007455d34e6193), commit `423e222159dfa159d788769554007455d34e6193`. Лицензия исходного проекта и сведения о зависимостях сохранены внутри архива. В исследованном порте DSDT и большинство vendor EFI заимствованы у Lenovo Y700; их пригодность для конкретного DBY-W09 не подтверждена.
